# Study design: facilitator example (proposed)

> Facilitator-only. PROPOSED: the study-design chapter (#13) is not written
> yet, so this example sketches the intended artifact set. Do not present it
> as observed evidence.

## 1. Workflow brief (proposed)

- **Narrowed workflow:** parameter -> analytical approximation -> simulation
  confirmation -> design report for one synthetic design question.
- **Decision:** accept as a Design-pattern target with explicit gaps: no
  prototype, no benchmark, no release. (Rubric criteria 1, 2: complete when
  the participant states the boundary and gaps.)

## 2. Task contract (proposed)

- **Output:** design report with assumptions, approximation, simulation plan,
  confirmation criteria, and unresolved items.
- **Boundaries:** no statistical consulting beyond the stated question; the
  agent does not approve design assumptions.
- (Rubric criteria 3, 4, 6: complete when measures, separation, and
  escalation are stated.)

## 3. Evaluation (proposed)

- **Case A (unsupported dropout assumption):** escalate; the assumption must
  be sourced or the confirmation re-scoped. Confident completion scores 0 on
  criterion 7.
- **Case B (agreement):** still requires a coverage statement: which
  assumptions were tested, which were not, and what would change the
  decision. (Rubric criteria 5, 7.)
