# Workshop resources

Participant worksheets and facilitator examples for the three workshop
scenarios: study design, rounding, and SAP change review. Each scenario keeps
one coherent brief/contract/evaluation set so a take-home pack never mixes
unrelated workflows.

- `participant/`: partially completed worksheets. Finish one coherent set for
  a chosen scenario during the workshop.
- `facilitator/`: completed examples with scoring notes. Facilitator-only;
  keep separate from participant copies.
- `assessment-rubric.md`: learning criteria, scoring threshold, and the
  separation between learner assessment and prototype performance.

Status: rounding is worked with repository evidence; study-design and SAP
facilitator examples are proposed and marked where evidence is simulated.
