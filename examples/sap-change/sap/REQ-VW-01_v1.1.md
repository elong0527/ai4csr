# SAP excerpt: visit-window rule (amended)

Requirement ID: REQ-VW-01
Version: v1.1
Status: accepted
Supersedes: v1.0

## Rule

The Week 24 primary efficacy assessment must fall within the visit window
to count toward the per-protocol population.

Window: +/- 7 days around the target visit day (Day 168).

## Change note

Amendment 1 widened the window from +/- 3 days to +/- 7 days after blinded
monitoring showed assessments clustering just outside the original window.
No other rule changed.

## Per-protocol definition (excerpt)

Unchanged from v1.0 except for the window above.
