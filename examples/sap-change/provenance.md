# Provenance: Pilot 1 teaching extracts

## Upstream sources

- Analysis datasets: RConsortium/submissions-pilot1, `adam/adadas.xpt` and
  `adam/adsl.xpt` (development repo for the FDA Pilot 1 submission).
  Identical copies: cdisc-org/sdtm-adam-pilot-project,
  `updated-pilot-submission-package/900172/m5/datasets/cdiscpilot01/analysis/adam/datasets/`.
- SAP rule: CDISCPILOT01 final SAP, Section 8.2 (Assessment Windows), as
  appended to the study report (`adam/cdiscpilot_docs/cdiscpilot01.pdf`).
- Reported results: CSR Section 11.4.1, Table 14-3.01 (ADAS-Cog change
  baseline to Week 24, LOCF).
- Analysis code: submissions-pilot1 `vignettes/tlf-primary.Rmd` (Step 2
  filter) and `R/eff_models.R` (ANCOVA with Type III sums of squares).

Retrieved 2026-09-08.

## Extracts in this directory

- data/adsl_extract.csv: 254 rows (sha256 eb9652e0b2affca97114c24aa79f1f9e6d679d97dc2459b11b414dc5edab42c6)
- data/adadas_week24_extract.csv: 257 rows (sha256 f0c6a0baf7b9f25bdebc15922c8a378db4cd02d3fc411feee399d4d73e07f914)

Generated by `extract_pilot1.py` (pyreadstat + pandas). String columns are
quote-preserved so R does not coerce the character site group (SITEGR1) to
numeric; `select_week24.R` additionally coerces it to a factor. Getting this
wrong moves the dose-response p-value from 0.245 to 0.201.

## Scope boundaries

- Visit assignment (AVISITN) is taken as given from ADaM. The example
  re-derives Week-24 record *selection* only.
- The v1.1 amendment is constructed teaching material, not a real change.
