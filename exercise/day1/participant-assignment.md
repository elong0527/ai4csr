# Participant assignment

This is a synthetic teaching exercise, not an analysis of KEYNOTE-189 trial
data. Using only the protocol and `kn189-synthetic-adsl.csv`, use R to identify
the protocol-defined analysis population and summarize its age distribution.

Report the randomized-record count, nonmissing and missing `AGE` counts, mean,
standard deviation, median, Q1, Q3, minimum, and maximum. State the R quantile
method. Include the executed R code, protocol sources, assumptions, and
questions for human review. Do not modify the input file or search for or use
published KEYNOTE-189 results.

Protocol: https://cdn.clinicaltrials.gov/large-docs/80/NCT02578680/Prot_SAP_001.pdf
